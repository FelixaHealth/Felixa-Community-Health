R Held, not live. Nothing here sends an alert, confirms anything or triggers anything. These are unvalidated word rules: they miss a lot and can be wrong, so they only point at messages for a person to read.

Why is everything held?

A High Risk alert may only go live when a named, qualified safeguarding reviewer, an independent second reviewer and an approved emergency protocol exist. This app has none of them, so every item stays held.{% if safety.missing %} Still missing: {{ safety.missing|join('; ') }}.{% endif %} The app does not keep who wrote a message, so it reads every message as one speaker: it can see a single message that threatens, but not an exchange between two people.
