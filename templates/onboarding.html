Using Discord? Add the Vibe Check bot

The Vibe Check bot checks the mood of a Discord channel from inside Discord. Add it to your server with the button, choose the server in the window that opens, and the bot appears in your member list. This page stays open in this tab.

{{ icon('link') }} Add the bot to my Discord server

It asks Discord for five permissions: view channels, read message history, send messages, embed links and attach files. You approve them on Discord's own page, and you can remove the bot at any time. The bot works inside Discord and does not send messages to Felixa Community Health. To see a channel in a Felixa Community Health report, export the channel and add the file in a new check.

How to export a Discord channel
  1. Use a channel export tool such as DiscordChatExporter, or request your data package from Discord.
  2. Choose CSV or JSON, or copy the messages as text.
  3. Press New on your workplace page and drop the file in.
