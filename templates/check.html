Add what people have said

Bring in the messages you want checked, in whichever way is easiest. You can use more than one.

{{ dropzone() }}

Any kind of file with text in it: Excel (.xlsx, .xls), CSV, Word (.docx, .doc), PDF, plain text, JSON, RTF, PowerPoint, OpenDocument, web pages, email (.eml), subtitles and transcripts (.srt, .vtt) and more. A spreadsheet or CSV is read one row to a message, from a column called text, comment, content, message or transcript, or else the column that reads like prose. A column named channel or source splits it into separate sources, and each sheet of a workbook is its own source. A file identical to one already added is skipped. A file may be up to {{ max_file_mb }} MB, and one upload {{ max_upload_mb }} MB in all.

{{ dropzone(name='files', accept=audio, title='Drop a recording here, or click to choose', chips=['MP3', 'WAV', 'M4A', 'OGG', 'FLAC'], icon_name='mic') }}

{% if voice_ok %}Recordings are turned into text on this computer, then checked like any other message.{% else %}Turning speech into text needs an add-on that is not installed on this computer yet: pip install faster-whisper. Until then, add a transcript as a file or paste it.{% endif %}

Felixa Community Health fetches each public page from the internet and reads the text the page contains. That is the only time it connects outside this computer. Comments that a page loads with scripts after it opens (YouTube, Reddit, Instagram, Facebook, X) are not in that text, so they are not read. Comments written into the page itself, as on most forums and blogs, are read, but as plain lines of text with no names or times. Pages behind a login, such as Discord or WhatsApp, cannot be read from a link: export those and add the file.

Hide people's names?

Incognito mode takes names out of the messages before anything reads them.

Hide people's names

Incognito replaces the name at the start of each chat line, @mentions and email addresses, and it does so in the saved messages too, for good. A name typed inside a sentence cannot be found reliably and stays, and so do file and channel names, so rename a file that has a person's name in it before adding it. Times of day are left out of the labels, tables, PDF and CSV in the Over time section while Incognito is on.
